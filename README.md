# IJMM POS

Punto de venta, inventario y control de caja para Windows. Funciona sin internet. Desarrollado por [IJMM System](https://ijmmsystem.com/productos/ijmm-pos).

## Descarga

**Versión 1.1.0** — Windows 10/11 (64 bits) — 85 MB

[Descargar IJMM-POS-Setup-1.1.0.exe](https://github.com/johao2/ijmm-pos/raw/main/IJMM-POS-Setup-1.1.0.exe)

SHA-256: `13cb2db95c6f649a06646737ca6278f8fb4a55a79f2d517b48ff9bcfaef6d3fb`

## Instalación

1. Ejecuta el instalador. Si Windows muestra "Windows protegió su PC", elige **Más información → Ejecutar de todas formas**.
2. Abre **IJMM POS** desde el escritorio.
3. Registra los datos de tu negocio y crea tu usuario administrador.

Incluye **15 días de prueba** con todas las funciones. Para seguir registrando ventas después, compra tu licencia en https://ijmmsystem.com/productos/ijmm-pos#precios
