# IJMM POS

Punto de venta, inventario y control de caja para Windows. Funciona sin internet. Desarrollado por [IJMM System](https://ijmmsystem.com/productos/ijmm-pos).

## Descarga

**Versión 1.2.1** — Windows 10/11 (64 bits) — 85 MB

[Descargar IJMM-POS-Setup-1.2.1.exe](https://github.com/johao2/ijmm-pos/raw/main/IJMM-POS-Setup-1.2.1.exe)

SHA-256: `e65222615023f6bde47949f07d9e17de65d1b43ef618f0bb897e0951e7cc7de3`

## Instalación

1. Ejecuta el instalador. Si Windows muestra "Windows protegió su PC", elige **Más información → Ejecutar de todas formas**.
2. Abre **IJMM POS** desde el escritorio.
3. Registra los datos de tu negocio y crea tu usuario administrador.

Incluye **15 días de prueba** con todas las funciones. Después, continúa con una suscripción mensual o anual en https://ijmmsystem.com/productos/ijmm-pos#precios

Soporte: https://ijmmsystem.com/contacto
