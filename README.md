# IJMM POS

Punto de venta, inventario y control de caja para Windows. Funciona sin internet. Desarrollado por [IJMM System](https://ijmmsystem.com/productos/ijmm-pos).

## Descarga

**Versión 1.3.4** — Windows 10/11 (64 bits) — 85 MB

[Descargar IJMM-POS-Setup-1.3.4.exe](https://github.com/johao2/ijmm-pos/raw/main/IJMM-POS-Setup-1.3.4.exe)

SHA-256: `97a3ef755111619f61ae492afa0f03bd3e1f122443afab1df8e5898eb1e20254`

## Instalación

1. Ejecuta el instalador. Si Windows muestra "Windows protegió su PC", elige **Más información → Ejecutar de todas formas**.
2. Abre **IJMM POS** desde el escritorio.
3. Registra los datos de tu negocio y crea tu usuario administrador.

Incluye **15 días de prueba** con todas las funciones. Después, cómprala desde el mismo sistema (Licencia → Comprar en línea) o en https://ijmmsystem.com/productos/ijmm-pos#precios
